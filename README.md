# Cadastro interativo

Exercício de JavaScript com formulário, validação, cadastro em array e busca
dinâmica de alunos.

## Executar

Abra `index.html` no navegador. Não há dependências para instalar.

## O que foi implementado

- Cadastro sem recarregar a página, usando `submit` e `preventDefault()`.
- Validação de nome com pelo menos 3 caracteres e nota entre 0 e 10.
- Atualização da tabela a partir de um array em memória.
- Busca por nome enquanto o usuário digita; `Escape` limpa a busca.
- Resultado "Aprovado" para média igual ou superior a 6,0.

Os dados ficam apenas na memória da página e são apagados ao recarregá-la.
